常见问题列表

灵卡自带模型额度吗？
不带。灵卡使用你自己的 API Key，Provider 和模型都在设置里选。这样你可以用自己的额度、自己的计费方式，也可以随时换模型。
支持哪些模型？
设置页会列出当前可用的 Provider，包括 OpenAI 兼容接口、Anthropic、DeepSeek、通义千问等，以实际列表为准。选 Provider、填模型 id 和 API Key 即可；支持 reasoning 的模型还能调思考深度。
数据存在哪里？
会话、设置、记忆和卡片资产都存在本机用户目录（Windows 的 %APPDATA%、macOS 的 ~/Library/Application Support）。覆盖安装和升级不会清掉它们。调用模型时，卡片内容会发送给你选择的模型服务商。
为什么第一次打开会被系统拦截？
安装包没有购买代码签名证书，也没有做 macOS 公证，所以 Windows SmartScreen 和 macOS Gatekeeper 会先拦一下。Windows 点「更多信息 → 仍要运行」；macOS 右键打开，或执行 xattr -dr com.apple.quarantine /Applications/灵卡.app。
怎么接入飞书？
在桌面端「设置 → 飞书接入」扫码创建应用，然后到飞书开发者后台把订阅方式设为「使用长连接」，订阅消息与卡片回调事件，并开通私聊和群 @ 两个权限。完整步骤见 文档的接入飞书一节。
群里 @ 机器人没反应？
私聊能收不代表群 @ 能收，这是两个独立权限。到飞书开发者后台确认已订阅 im.message.receive_v1，并开通 im:message.group_at_msg:readonly；只开私聊权限时，群里 @ 是不会到灵卡这里的。
按钮点了没反应？
先在「设置 → 飞书接入」里确认「卡片回调绑定」已打开。这个开关对新会话生效，已经建立的会话不会中途接上回调，开完开关后新开一个会话再试。如果按钮是跳转类型，则不需要回调绑定，它会直接在客户端打开链接。
能把卡片发给别人或群吗？
可以。发到来源会话之外的目标时，灵卡会先给触发这一轮的人发一张确认卡，他点了允许才会真正投递。这道确认不受设置里「发送前确认」开关影响，避免卡片被发到意料之外的地方。
能定时发卡片吗？
支持。在对话里描述「每天 9 点发一张站会卡」这样的规则，灵卡会创建定时任务，到点以你的身份发送。补跑规则是「漏跑不补」：错过的这一轮不会在下次启动时补发。
支持飞书国际版（Lark）吗？
支持。设置页可以在飞书与 Lark 的 API 域名之间切换；连接方式和权限配置一致，只是应用的租户不同。
怎么更新？会打断会话吗？
应用启动时会静默检查版本。有新版本时左上角出现升级箭头，下载完成后由你决定什么时候重启安装，不会自动装。安装过程会重启应用，正在进行的会话建议先等它跑完。
源码开源吗？
源码不公开。安装包、更新记录和反馈都在 lingka-releases 仓库里，下载和更新都从那里取。
