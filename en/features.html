Capabilities

From one sentence,
to a card you can click.

Lingka keeps design rules, lint checks and the Feishu loop on one path. Every capability is visible in the desktop app — you can inspect it, change it and start over. No black box.

Natural language

Say what you need and the card starts taking shape

You don't need to figure out JSON first. Describe the card, who it's for and what you want people to do — Lingka proposes the structure, then tunes the layout.

  • A sentence, a document or a screenshot can be the input
  • Multi-turn edits touch only what you mention
  • Past cards and templates work as a starting point

Design rules built in

Looking good isn't luck

Palette, spacing, type, borders and buttons all come from one set of design tokens. The rules live in the generation pipeline and in lint, so the card looks designed before anything else.

  • Three columns max, three buttons max — excess is stopped early
  • Desktop and mobile canvases, what you see is what you get
  • Dark theme adapts automatically, no second version to draw

Lint as a hard gate

Not shipping is also a safeguard

Structure, colors, icons, buttons, links and @ mentions are checked one by one. If lint fails, the card cannot go out — there is no “send it and fix later” path.

  • Icons must be real tokens from the official set
  • A malformed link button is an error, never a silent no-op
  • A content ledger blocks silent rewrites right before sending

Three-column studio

When you want to take over, the tools are there

The studio takes a card apart: structure tree on the left, canvas in the middle, fields on the right. Change one and the other two follow.

  • Switch between DSL, standard 2.0 and RAW at any time
  • Edit on the page, then preview right away
  • Undo is supported, so a bad edit isn't final

The Feishu loop

Scan to create an app, callbacks come back to the chat

No server to build. Scan a QR code to create the Feishu app; the desktop app receives messages and card callbacks over a long connection, with no public address to maintain.

  • Guided app creation for permissions and events
  • DMs, groups and topic groups each get their own session scope
  • Button and form callbacks land in the current conversation
  • Send as the user; forwarded cards are imported automatically

Automation & memory

Like a teammate who remembers

Scheduled cards go out on time; preferences, recurring layouts and past decisions are remembered. Long conversations compact themselves, and separate sessions don't interfere.

  • Scheduled tasks send as the user; missed runs aren't backfilled
  • Remembers your preferences and go-to layouts
  • Long chats compact automatically; old sessions archive by age

Extensible

Whatever's missing, you can plug in

Skills and plugins widen what it can do; the icon library brings your company's own icons along. It isn't tied to one model either — switch whenever you like.

  • Skills and a plugin subsystem, mounted on demand
  • Local icon library and online icons, chosen by meaning
  • OpenAI-compatible, Anthropic, DeepSeek and more providers
