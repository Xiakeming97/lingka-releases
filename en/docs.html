Getting started

Lingka is a desktop application. Installers are available for Windows and macOS and are published on GitHub Releases. No extra server is required after installation.

Requirements

  • Windows 10 / 11, 64-bit.
  • macOS on Apple silicon or Intel.
  • Node.js 20 or newer if you use the command line.

Install

  1. Open the download page and pick your platform.
  2. Download and run the installer, then follow the prompts.
  3. If the first launch is blocked, allow it as described below.
!

The installer is not code-signed and is not notarized for macOS.Windows SmartScreen warns once — choose “More info → Run anyway”. On macOS, right-click the app and choose Open, or run the command below.

xattr -dr com.apple.quarantine /Applications/Lingka.app

Full install steps and update notes are on the download page.

Configure a model

Open Settings → Models & keys and connect a model. Lingka has no bundled quota — you use your own API key.

  1. Choose a provider. Settings lists the available ones, including OpenAI-compatible endpoints, Anthropic, DeepSeek and Qwen. Use whatever the list shows.
  2. Pick or enter a model id.
  3. Enter the API key for that provider.
  4. Adjust reasoning depth if you need it. Only models that support reasoning emit a thinking stream.

API keys are encrypted and stored locally, never uploaded to a Lingka server. Changing provider or model doesn't affect existing sessions — the next message uses the new settings.

Connect Feishu

The desktop app receives messages and card callbacks over a Feishu long connection. No public address, no server of your own.

  1. Open Settings → Feishu, scan the QR code, and confirm app creation.
  2. Wait until the status shows “Connected”.
  3. In the Feishu developer console, go to Events & Callbacks → Subscription mode and choose “Long connection”.
  4. Subscribe to im.message.receive_v1 and card.action.trigger.
  5. Grant im:message.p2p_msg:readonly and im:message.group_at_msg:readonly.
  6. Send “make me a card” in a DM to verify, then @ the bot in a group.
!

DMs and group @ mentions are two separate permissions.With only the DM permission, group mentions never reach Lingka — and vice versa. Grant both to use both.

i

For buttons to respond, turn on card callback binding in the Feishu settings. The switch applies to new sessions; sessions already running won't pick up callbacks mid-way.

Build your first card

Describe the card you want right in the chat — no JSON needed. Here are a few prompts you can use as-is.

Turn this week's sales into a report card: three metrics, two takeaways, and a "View details" link button at the bottom.

Make an onboarding guide card with three sections — day one, week one, month one — three bullets each.

Make a service alert card: title "Order service latency", red warning style, one suggested action and two buttons (Retry / View logs).

What happens next

  1. Generate: structure first, content second.
  2. Polish: layout, copy, icons and button styles.
  3. Lint: structure, colors, icons, buttons and links, item by item.
  4. Preview: check it on the desktop and mobile canvases.
  5. Send: to a Feishu group or DM.

When lint fails, Lingka lists every problem and goes back to fix them. A content ledger also verifies the card right before sending, so nothing is silently rewritten at the last moment.

To change the structure yourself, use the three-column studio. Or just tell Lingka which part to change — everything else stays put.

Command line

Besides the desktop app, you can run the same agent from the command line at the project root.

npm install
npm run config
npm run agent
  • npm run config walks you through provider, model and API key.
  • npm run agent opens a terminal chat; you can override the model per run.
  • Install dependencies with npm only. Node.js 20 or newer is required.
npm run agent -- --provider openai --model gpt-5
i

The command line does not connect Feishu callbacks — those come from the desktop app's long connection. Use the desktop app when buttons and forms need to return to the conversation.

Data & privacy

Sessions, settings, memory and the card library are stored in your local user directory.

  • Windows: %APPDATA%
  • macOS: ~/Library/Application Support

Reinstalling or upgrading keeps this data. API keys are encrypted on your machine; when a model is called, card content is sent to the provider you selected.

Lingka runs no relay service and doesn't copy card content anywhere else. Your data goes exactly two places: your machine, and the model provider you chose.
