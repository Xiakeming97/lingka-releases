Card library

Every card you send,
stays in the library

Forwarded cards, saved conversations, editor drafts — all in one place. Next time you need something similar, start from that card instead of describing the layout again.

  • Forward a card, it lands in the library

    Forward a Feishu card to the Lingka bot and it reads the original card into the library. The “auto-import” switch in the toolbar and the one in settings are the same setting.

  • Find it by name or tag

    Every entry keeps its source, save date and schema version. Filter by name or tag, and see at a glance where the card came from.

  • Ask AI to build from it

    Pick a card and choose “Build from this”. It reuses the layout, columns and button placement, and only replaces the content.

  • Edit it right there

    Edit fields, polish it, or send it straight to Feishu. You're editing the saved card itself — no need to start over in the chat.

  • Source and version are kept

    Each card records its source, save time, schema 2.0 version and card ID. Older 1.0 cards still open for inspection.

  • The library stays on your machine

    Cards live in the desktop app's local data directory. No extra cloud service, and no handing company cards to a third party.

FAQ

Before you start,
you might be wondering

Still stuck? Open an issue on GitHub, or check what has already been fixed in the release notes.

Visit GitHub
Does Lingka include model credits?
No. Lingka uses your own API key, with the provider and model chosen in settings. That way you use your own quota and billing, and can switch models at any time.
Where is my data stored?
Sessions, settings, memory and the card library live in your local user directory (%APPDATA% on Windows, ~/Library/Application Support on macOS). Reinstalling or upgrading doesn't remove them. When a model is called, card content is sent to the provider you chose.
Why is the first launch blocked?
The installer isn't code-signed and isn't notarized for macOS, so Windows SmartScreen and macOS Gatekeeper warn once. On Windows choose “More info → Run anyway”; on macOS right-click and Open, or run xattr -dr com.apple.quarantine /Applications/Lingka.app.
Nothing happens when I @ the bot in a group?
Receiving DMs does not mean receiving group @ mentions — they are two separate permissions. In the Feishu developer console, confirm im.message.receive_v1 is subscribed and im:message.group_at_msg:readonly is granted. With only the DM permission, group mentions never reach Lingka.
