Install guide

The first launch
gets blocked once

The installer isn't code-signed and isn't notarized for macOS. The two systems handle it differently — follow the steps below.

Windows SmartScreen

  1. Double-click the installer and wait for the SmartScreen prompt.
  2. Click “More info”.
  3. Click “Run anyway”, then finish the installer.

This is the standard warning for unsigned apps — it doesn't mean the installer is damaged.

macOS Gatekeeper

  1. In Applications, right-click Lingka and choose Open.
  2. Click Open again in the dialog.
  3. If it's still blocked, run the command below in Terminal.
xattr -dr com.apple.quarantine /Applications/Lingka.app
!

The installer isn't notarized or signed with a purchased certificate, so the system warns once. Once allowed, it behaves like any other desktop app — no repeated prompts.

Data location

Your data,
in your own user folder

Sessions, settings, memory and the card library stay on your machine. Reinstalling and upgrading don't touch them.

  • Windows: %APPDATA%
  • macOS: ~/Library/Application Support
  • API keys are encrypted on your machine
