Frequently asked questions

Does Lingka include model credits?
No. Lingka uses your own API key, with the provider and model chosen in settings. That way you use your own quota and billing, and can switch models at any time.
Which models are supported?
Settings lists the providers currently available, including OpenAI-compatible endpoints, Anthropic, DeepSeek and Qwen — use whatever the list shows. Choose a provider, enter the model id and API key. Models that support reasoning also expose a thinking-depth setting.
Where is my data stored?
Sessions, settings, memory and the card library live in your local user directory (%APPDATA% on Windows, ~/Library/Application Support on macOS). Reinstalling or upgrading keeps them. When a model is called, card content is sent to the provider you chose.
Why is the first launch blocked?
The installer isn't code-signed and isn't notarized for macOS, so Windows SmartScreen and macOS Gatekeeper warn once. On Windows choose “More info → Run anyway”; on macOS right-click and Open, or run xattr -dr com.apple.quarantine /Applications/Lingka.app.
How do I connect Feishu?
In the desktop app, go to Settings → Feishu and scan the QR code to create the app. Then set the subscription mode to “Long connection” in the Feishu developer console, subscribe to message and card-callback events, and grant both the DM and group-mention permissions. The full walkthrough is in the Feishu section of the docs.
Nothing happens when I @ the bot in a group?
Receiving DMs does not mean receiving group @ mentions — they are two separate permissions. In the Feishu developer console, confirm im.message.receive_v1 is subscribed and im:message.group_at_msg:readonly is granted. With only the DM permission, group mentions never reach Lingka.
Buttons don't respond when clicked?
First check that “card callback binding” is on in Settings → Feishu. It only applies to new sessions — existing sessions won't pick up callbacks mid-way, so start a new session after enabling it. Link buttons are the exception: they open in the client without needing callback binding.
Can I send a card to someone else or to a group?
Yes. When the target is outside the originating conversation, Lingka first sends a confirmation card to the person who triggered the turn; the card is only delivered after they approve. This confirmation is independent of the “confirm before send” setting, so cards can't be delivered somewhere unexpected.
Can Lingka send cards on a schedule?
Yes. Describe a rule like “send a standup card every day at 9” and Lingka creates a scheduled task, sending as you. Missed runs are not backfilled — a skipped run won't fire the next time the app starts.
Is Lark (international Feishu) supported?
Yes. Settings lets you switch the API domain between Feishu and Lark. The connection method and permission setup are the same — only the tenant differs.
How do updates work? Will they interrupt a session?
The app checks for versions quietly at startup. When one is available, an update arrow appears in the top-left, and you decide when to restart and install — nothing installs on its own. The installer restarts the app, so let any running session finish first.
Is the source code open?
No, the source isn't public. Installers, release notes and feedback all live in the lingka-releases repository, which is also where downloads and updates come from.
