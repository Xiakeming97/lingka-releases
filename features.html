能力

从一句话，
到一张能点的卡。

灵卡把设计规则、lint 校验和飞书闭环放在同一条链路上。每一项能力都能在桌面端看见、改、重来——不是黑盒。

自然语言生成

把需求说出来，卡片就开始成型

不用先想清楚 JSON 结构。描述你要一张什么卡、发给谁、想让人做什么，灵卡先给结构，再调版式。

  • 一句话、一段文档、一张截图都能作为输入
  • 多轮修改只动你提到的那一处，不推倒重来
  • 历史卡片与模板可以直接当底子

设计约束内建

好看不是碰运气

色板、间距、字号、描边、按钮都来自同一套设计 token。规则写进生成链路，也写进 lint，卡片先像设计过，再谈生成。

  • 最多 3 栏、按钮不超过 3 个，超出会主动拦
  • 桌面与手机两种画布，所见即所得
  • 深色主题自动适配，不用再画一版

lint 硬校验

发不出去，也是一种保护

结构、颜色、图标、按钮、链接、@ 逐项检查。lint 不通过就发不出去，没有“先发出去再说”这条路。

  • 图标必须是官方枚举里的真实 token
  • 跳转按钮的形状写错会直接报错，不会静默失效
  • 发送前还有内容账本，防止卡片被静默改写

三栏工坊

想自己动手时，工具都在

工坊把一张卡拆开给你看：左边结构树，中间画布，右边字段。改哪一处，另外两处跟着动。

  • DSL、标准 2.0、RAW 三种视图随时切换
  • 纸面就地编辑，改完直接预览
  • 支持撤回，改坏了也能退回去

飞书闭环

扫码建应用，回调回到对话

不用自己搭服务。扫码创建飞书应用，桌面端用长连接接收消息和卡片回调，断网重连也不用管公网地址。

  • 扫码创建应用，权限和事件一步步引导
  • 私聊、群聊、话题群按各自粒度进会话
  • 按钮与表单回调直接注入当前会话
  • 支持以用户身份发送；转发卡片自动入库

自动化与记忆

像一个记得住事的同事

定时任务到点自动发；偏好、常用版式和历史决定会被记住。长对话自动压缩，多个会话互不打扰。

  • 定时任务以用户身份发送，漏跑不补
  • 记住你的偏好与常用版式
  • 长对话自动压缩，老会话可按天归档

可扩展

缺什么，接什么

Skills 和插件扩展它的能力面；图标库可以把公司自己的图标带进来。模型也不绑定，想换就换。

  • Skills 与插件子系统，按需挂载
  • 本地图标库与在线图标，按语义挑选
  • OpenAI 兼容、Anthropic、DeepSeek 等多家 Provider
