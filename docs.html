快速开始

灵卡是一个桌面应用。Windows 和 macOS 都有安装包，安装包发布在 GitHub Releases，安装后不需要额外的服务端。

系统要求

  • Windows 10 / 11，64 位。
  • macOS，Apple 芯片或 Intel 芯片。
  • 只用命令行方式时，需要 Node.js 20 或更高版本。

安装

  1. 打开 下载页，选择你的系统。
  2. 下载并运行安装包，按提示完成安装。
  3. 第一次打开被系统拦截时，按下面说明放行。
!

安装包没有购买代码签名证书，也没有做 macOS 公证。Windows SmartScreen 会先拦一下，点「更多信息 → 仍要运行」；macOS 右键应用选「打开」，或执行下面的命令。

xattr -dr com.apple.quarantine /Applications/灵卡.app

更完整的安装步骤和更新说明见 下载页的安装说明。

配置模型

打开「设置 → 模型与凭证」，把模型接上。灵卡不内置额度，使用你自己的 API Key。

  1. 选择 Provider。设置页会列出可用的服务商，包括 OpenAI 兼容接口、Anthropic、DeepSeek、通义千问等，以实际列表为准。
  2. 选择或填写模型 id。
  3. 填入对应 Provider 的 API Key。
  4. 需要时调整思考深度。只有支持 reasoning 的模型会产出思考过程。

API Key 加密保存在本机，不会上传到灵卡自己的服务器。换 Provider 或模型不影响已有会话，下一条消息就会用新配置。

接入飞书

桌面端通过飞书长连接接收消息和卡片回调，不需要公网地址，也不用自己搭服务。

  1. 打开「设置 → 飞书接入」，扫码连接，按提示确认创建应用。
  2. 等待连接状态变成「已连接」。
  3. 到飞书开发者后台 → 事件与回调 → 订阅方式，选择「使用长连接」。
  4. 订阅 im.message.receive_v1 与 card.action.trigger 两个事件。
  5. 开通 im:message.p2p_msg:readonly 与 im:message.group_at_msg:readonly 两个权限。
  6. 私聊发一句「帮我做张卡」验证；再到群里 @ 机器人验证。
!

私聊和群 @ 是两个独立权限点。只开私聊权限时，群里 @ 不会到灵卡这里；反过来也一样。两个权限都开通，两种场景才都能用。

i

想让按钮点了有反应，还要在「飞书接入」里打开卡片回调绑定。开关对新会话生效，已经建立的会话不会中途接上回调。

生成第一张卡片

在对话里直接描述你想要的卡，不用先想 JSON。下面是几个可以直接用的例子。

把本周的销售数据做一张周报卡：三个指标、两句结论、底部放一个「查看明细」跳转按钮。

做一张新人入职指引卡，按第一天 / 第一周 / 第一个月分三段，每段三条。

做一张服务告警卡：标题写「订单服务延迟」，红色警示，附一条处理建议和两个按钮（重试 / 查看日志）。

生成之后

  1. 生成：先出结构，再补内容。
  2. 润色：调版式、文案、图标和按钮样式。
  3. lint：结构、颜色、图标、按钮、链接逐项检查。
  4. 预览：桌面和手机两种画布看效果。
  5. 发送：发到飞书群或私聊。

lint 不通过时，灵卡会把问题逐条列出来并回去改。发送前还有内容账本校验，防止卡片在最后一刻被静默改写。

想自己动结构，用「工坊」的三栏编辑器；也可以直接告诉灵卡改哪一处，它会保留其余部分。

命令行使用

除了桌面端，也可以在项目根目录用命令行跑同一套 Agent。

npm install
npm run config
npm run agent
  • npm run config 会引导你选择 Provider、模型并写入 API Key。
  • npm run agent 打开命令行对话；也可以临时指定模型。
  • 依赖只用 npm 安装。Node.js 需要 20 或更高版本。
npm run agent -- --provider openai --model gpt-5
i

命令行不会自动接入飞书回调；卡片回调由桌面端的长连接提供。需要按钮和表单回到对话时，请使用桌面端。

数据与隐私

会话、设置、记忆和卡片资产都保存在本机的用户目录。

  • Windows：%APPDATA%
  • macOS：~/Library/Application Support

覆盖安装和升级不会清掉这些数据。API Key 加密保存在本机；调用模型时，卡片内容会发送给你选择的模型服务商。

灵卡不运营中转服务，也不会把卡片内容另存到第三方。数据的去向只有两个：你的本机，和你选择的模型服务商。
