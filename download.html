安装说明

第一次打开，
系统会拦一下

安装包未购买代码签名证书，也未做 macOS 公证。两个系统的放行方式不一样，按下面的步骤操作即可。

Windows SmartScreen

  1. 双击安装包，等待 SmartScreen 提示出现。
  2. 点提示框里的「更多信息」。
  3. 点「仍要运行」，然后按安装向导完成安装。

这是未签名应用的标准提示，不代表安装包损坏。

macOS Gatekeeper

  1. 在「应用程序」里右键灵卡，选择「打开」。
  2. 在弹窗里再点一次「打开」。
  3. 如果仍被拦截，在终端执行下面的命令。
xattr -dr com.apple.quarantine /Applications/灵卡.app
!

安装包没有做公证，也没有买签名证书。所以系统会先拦一下。放行之后，它就是一个普通的桌面应用，不会反复弹窗。

数据位置

你的数据，
在你的用户目录里

会话、设置、记忆和卡片资产都存在本机。覆盖安装和升级不会影响它们。

  • Windows：%APPDATA%
  • macOS：~/Library/Application Support
  • API Key 加密保存在本机
