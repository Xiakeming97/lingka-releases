# 灵卡（Lingka）

用自然语言描述，自动生成、校验、发送**飞书 CardKit 2.0 交互式卡片**，并处理按钮回调。

> 安装包在这里的 **Releases** 页。源码不公开。

## 下载

| 系统 | 下载哪个 |
| --- | --- |
| Windows 10/11 64 位 | `Lingka-Setup-<版本>.exe` |
| macOS（Apple 芯片） | `Lingka-<版本>-arm64.dmg` |
| macOS（Intel） | `Lingka-<版本>-x64.dmg` |

安装包**没有买代码签名证书**，所以两个系统第一次打开都会拦一下 —— 这是正常的，不是文件坏了。
下面各写了一句怎么办。

### Windows：SmartScreen

双击后可能弹「Windows 已保护你的电脑」→ 点「**更多信息**」→「**仍要运行**」。

### macOS：Gatekeeper

弹「**已损坏，无法打开**」（或"无法验证开发者"）—— 因为在做本地签名、没有公证。
两种办法任选：

- 右键点 App →「**打开**」→ 再点一次「打开」；
- 或者命令行：`xattr -dr com.apple.quarantine /Applications/灵卡.app`

## 第一次使用要配两样东西

### 一、模型与 API Key

打开「设置 → 模型」，选一个 Provider、填上你自己的 API Key。
（灵卡不自带模型额度，用的是你自己的 key。）

### 二、接入飞书

「飞书」页整页就是干这个的。**按顺序**走，第 3、5 步必须自己去开发者后台点，
扫码链接代填不了：

1. 点「扫码连接飞书」，用**飞书 App** 扫码，在确认页点「确认创建」。
   应用和它的 App ID / Secret 会自动建好并存进本机（密钥走系统加密），不用去后台复制粘贴。
   ⚠ 这一步只会**新建**应用，不会动你已有的任何应用。
2. 应用会自动连上，状态变「已连接」。
   ⚠ 飞书要求**后台先看到一条活着的连接**才允许把订阅方式存成长连接，所以这一步不能跳过。
3. 去**开发者后台 →「事件与回调 → 订阅方式」**，手动选「**使用长连接**」。
   订阅方式是敏感配置，不会随扫码链接下发，必须人工点。
4. 事件订阅勾 `im.message.receive_v1`，回调订阅勾 `card.action.trigger`（扫码时多半已预填）。
   想让卡片上的按钮真的能点，回到「飞书」页打开「卡片回调绑定」，**新会话生效**。
5. 去**「权限管理」**确认这两个都开通了：
   - `im:message.p2p_msg:readonly` —— 收私聊
   - `im:message.group_at_msg:readonly` —— 收群里的 @

   ⚠ **能收私聊不等于能收群里的 @**，是两个独立的权限点。缺了群那个，群里 @ 机器人
   **不会有任何反应** —— 消息在平台侧就不推过来了，本机什么线索都没有，看着像"机器人不回"，
   其实是"根本没收到"。
6. 验证：先发一条**私聊**；再把机器人拉进一个群、**@ 它**发一句。两条都通了才算接好。

## 更新

- **Windows**：启动时会静默检查，有新版时左上角出现一个**升级箭头**，点一下开始下载，
  下完再点一下重启安装。**不会自动装** —— 你的会话不会被没打招呼地重启掉。
- **macOS**：**没有自动更新**（包没做苹果签名，自动更新装不上），请回到这里下载新的 dmg 覆盖安装。
  覆盖安装**不影响**你的会话、设置和记忆。

## 数据在哪

全部在你的用户目录下（Windows `%APPDATA%`、macOS `~/Library/Application Support`），
不在安装目录里。**覆盖安装和升级都不会动它**；想彻底清掉就删掉那个目录。
